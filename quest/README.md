# KaLi Quest

Your own quest groups, in a rewritten objective tracker, for World of Warcraft Forever.

- `KaLiQuest`: the addon. Its [README](KaLiQuest/README.md) says what it does and how to install it.
- `KaLiQuest_Tests`: its in-game tests, run with `/kq test`. Players don't need it.

Found a bug? **Signaler un bug (Report a bug)**, the last line of the tracker's gear menu, or `/kq report`, gives a report to copy into a [new issue](https://github.com/Ikar-Rahl/Wow-KaLi-Quest/issues/new).
