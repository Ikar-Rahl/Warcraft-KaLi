# KaLi Recipe

A notebook of the recipes you come across, for World of Warcraft Forever, without spoiling the ones you haven't met.

- `KaLiRecipe`: the addon. Its [README](KaLiRecipe/README.md) says what it does and how to install it.
- `KaLiRecipe_Tests`: its in-game tests, run with `/kr test`. Players don't need it.
- `KaLiRecipe_Probe`: the in-game probe, for development only (`/krprobe`). Not shipped.
